# Olist-Dashboard
 Olist E-Commerce Sales &amp; Orders Analysis | Power BI
 
After i had completed a great training with ICTHUB I recently completed a Power BI project using the Olist Brazilian E-Commerce dataset.

The goal was to analyze sales, orders, customers, products, and delivery performance and turn the raw data into an interactive dashboard.
What I worked on:

• Data cleaning and transformation using Power Query
 • Data modeling and DAX measures
 • Sales and revenue analysis
 • Order and delivery performance analysis
 • Interactive filtering by date, customer, order, category, and state
 • Dashboard and data-table design

Some of the analysis includes revenue trends over time, top-performing states and categories, order status, late-order rates, and delivery performance.

This project helped me practice not only building visuals in Power BI, but also thinking about what questions the data can answer and how to communicate the results clearly.

Tools: Power BI | Power Query | DAX
